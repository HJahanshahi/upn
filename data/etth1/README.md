# ETTh1 Dataset

Hourly electricity transformer temperature data (17,420 observations).

## Download

Run `python examples/etth1/download_etth1.py` to download and prepare the data.

## Source

Zhou et al. (2021). *Informer: Beyond Efficient Transformer for Long Sequence
Time-Series Forecasting.* AAAI 35, 11106–11115.

https://github.com/zhouhaoyi/ETDataset

## Features Used (Section 5.4)

- **temperature**: Oil temperature (OT)
- **feature_1**: High useful load factor (HUFL)
- **feature_2**: High useless load factor (HULL)
